# Imágenes de Proyectos

Aquí van las imágenes/screenshots de tus proyectos.

## Estructura

- **localstock/** - Screenshots del proyecto LocalStock
  - dashboard.png (o dashboard.jpg)
  - inventario.png
  - ventas.png
  
- **tesis/** - Screenshots del Sistema de captura de datos
  - captura.png
  - sincronizacion.png
  - offline.png

## Cómo agregar las imágenes

1. Crea carpetas con el nombre del proyecto (localstock, tesis)
2. Coloca tus screenshots dentro
3. Usa nombres descriptivos: dashboard, inventario, ventas, etc.
4. Formatos soportados: PNG, JPG, JPEG, GIF, WebP

Las imágenes se mostrarán automáticamente en el portafolio.
