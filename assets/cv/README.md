# Currículum

Aquí coloca tu archivo de currículum en PDF.

## Cómo agregarlo

1. Coloca tu CV en PDF en esta carpeta
2. Nombra el archivo como: `CV_Miguel_Ernesto_Capote.pdf`
3. En el portafolio, actualiza la URL en la configuración:
   ```
   cvUrl: "assets/cv/CV_Miguel_Ernesto_Capote.pdf"
   ```

El botón "Descargar CV" aparecerá automáticamente en el portafolio.
